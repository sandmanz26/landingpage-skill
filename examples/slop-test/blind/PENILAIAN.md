# Uji buta AI slop: 5 homepage

Lima halaman, lima bisnis berbeda, dibuat dengan cara berbeda (dengan dan tanpa skill). Hurufnya diacak.
Jangan buka `KUNCI-jangan-dibuka-sebelum-menilai.json` sebelum selesai menilai.

Buka `X/index.html` di browser (desktop dan ponsel), atau lihat `X-desktop.png` / `X-ponsel.png`.

Untuk tiap huruf, isi:

| | A | B | C | D | E |
| --- | --- | --- | --- | --- | --- |
| Skor slop 1-10 (10 = sangat terasa AI slop) | | | | | |
| Skor kualitas desain 1-10 | | | | | |

Lalu per huruf, tulis bebas:
1. **Bagian yang terasa slop** (sebut bagian: hero, kartu, ikon, warna, font, animasi, teks, tata letak...).
2. **Kenapa** terasa slop: apa yang membuat Anda tahu ini buatan AI / template?
3. **Bagian yang tidak slop** (kalau ada) dan kenapa.

Catatan: semua gambar adalah ilustrasi atau placeholder (tidak ada foto), nomor WA dan alamat adalah contoh.
Nilai desainnya, bukan kelengkapan datanya.
