# AI defaults

What a model produces when a decision is left open. None is forbidden outright; each one needs a
reason in the spec if it stays. Severity of the ones the inspector detects is set in
`rules/style-defaults.json` and can be raised or lowered by the team.

| Default | Why models reach for it | Use instead |
| --- | --- | --- |
| Purple, violet or indigo gradient | Framework default colours, thousands of templates | A colour from the subject or the brand; one flat accent |
| Cream ground with terracotta or rust accent | The "assistant palette": the model's own house style | A palette from the subject's material, place or brand |
| Inter or a system font everywhere | The most common choice in the data | A face with a voice that fits the subject, per the direction |
| Centred headline over two buttons ("Get started" + "Learn more") | The most common hero | One action; a composition from the direction |
| Small uppercase label above every heading (eyebrow) | Template habit | Put the information in the heading or drop it |
| Three icon cards in a row | SaaS template | A numbered list, a demo, one feature in depth |
| Emoji or generic icons as visuals | Cheap filler | Real pictures, drawings of the subject, or nothing |
| Blobs, glass panels, glows | 2021–2024 trends that dominate the data | Flat fields of colour, real pictures |
| Soft shadow and 8–12px radius on everything | Framework defaults | One chosen shape system |
| Fade-up on every section | Animation-library default | Motion with a function (`motion/functions.md`) |
| "Unlock", "Supercharge", "Seamless", "All-in-one", "Solusi terbaik" | Frequent marketing words | Specific verbs and real numbers |
| Three testimonial cards with round avatars and five stars | Template | One real quote, large, with name and role, or none |
| Three pricing columns with "Most popular" in the middle | Template | The structure of the real offer |
| Generic statistics ("10k+ users, 99.9% uptime") | Placeholders that look convincing | Real numbers, or nothing |
| The same padding on every section | No rhythm decided | Dense and airy sections alternating; one grid break |
| A four-column footer of links | Template | The footer the site needs; often the name, contact and a few links |
