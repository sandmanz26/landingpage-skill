# References and copyright

Learn patterns from references; never copy their assets or their recognisable identity. This is
practical guidance, not legal advice.

1. **At least three sources.** No design takes its references from a single site.
2. **One role per reference.** Each reference supplies named decisions only ("layout and rhythm from
   A", "type scale from B"). Palette, layout and style never all come from the same source. Write
   the roles in the spec.
3. **No assets.** No logos, mascots, illustrations, photographs, icons, copy or code from a reference.
4. **No signature brand identity.** A well-known brand's distinctive colour, mascot or banner style is
   never a main element unless that brand is the client. Entries marked `pattern_only` in the
   library are used through their tags, never shown as a visual reference.
5. **Logo-swap test.** Put the reference brand's logo on the result. If it looks like their site, it
   fails: change the decisions that came from that reference.
6. **Credit found pictures.** Pictures from open collections are downloaded into the project,
   credited in the footer and listed in the report with title, creator, licence and source page.
